# KukuSeat 桌宠提醒

本轮将已评审的原图小灰猫和慢气泡接入 AppKit。

- 监测并启用自动提醒时小猫常驻；暂停、锁屏中断或关闭提醒时隐藏。恢复监测后回到原位置。
- 拖动超过 4 pt 才算移动；拖动不触发静默。释放时保存屏幕和相对位置。断开显示器时回到可用屏幕，限制在可见工作区。
- 点击小猫或任一气泡，收起全部气泡并全局静默 30 秒，小猫保留。异常累计逻辑独立于显示，不因收起而清零。
- 右键隐藏小猫，状态栏“显示／隐藏小灰猫”可找回；隐藏偏好跨启动保存。
- 不抢键盘焦点；小猫与气泡各自使用非激活窗口，中间透明空白不拦鼠标。
- 每种异常保留自己的气泡；新增气泡依次用 1.8 秒缓缓吹起，同一轮位置稳定。恢复保持原指令，确认恢复加勾并保留三秒。
- 原图逐字节打包，绘制时去白底，不重画轮廓；只在肚皮区域轻微呼吸。系统“减少动态效果”关闭呼吸和缩放。
- 应用显示名改为 KukuSeat，应用图标为原图小灰猫加白底，状态栏使用早期白色实心 v4。

保留 bundle identifier、设置目录、签名要求、GitHub 仓库、更新清单密钥和旧下载文件名。发行脚本将 KukuSeat.app 装入旧名的更新归档根目录，兼容已发布客户端的校验；DMG 中显示 KukuSeat.app。旧安装经自动更新后仍可保留原来的磁盘路径，显示名为 KukuSeat。
