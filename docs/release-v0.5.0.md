# Kukusit v0.5.0

发布准备状态：78 项核心检查、设置迁移、原生计算设备/缩放检查、后台采集及便携包检查通过。开发包已安装到 Applications 并注册；最终证书签名与可视化核验等待构建 Mac 解锁及 codesign 钥匙串授权。尚未创建正式 v0.5.0 GitHub Release。

提醒改为可自行调优：默认持续偏离 5 秒、头部偏离 3°；时间可调 1–120 秒。角度、恢复、冷却、识别频率及更多姿态参数立即生效，支持预设和参数文件导入导出。旧窗口偏好保留，旧头部参考继续校验使用；新的口唇/眼周试验功能需要重新建立自然参考。

视频改用独立的原生预览层。脸部与肩部异步处理，肩部模型准备不再拖住第一帧；肩部默认 3 Hz、640×360 输入，保持有界任务与结果过期检查。原生 Vision 支持选择 CPU、GPU 或 Neural Engine 优先，不支持的阶段自动选择设备。MediaPipe 肩部仍使用 CPU。

增加持续手靠近嘴唇提示、可关闭的口唇/嘴角/单侧眯眼变化试验，以及可调的下颌放松定时自检。不会将闭唇判成牙齿紧绷，不声称区分磨牙、咬唇或哪颗牙接触嘴唇。原有左右差异作为个人参考，不能据此判断大小脸病因。

改为标准 macOS 应用，提供 Dock 与 Applications 安装流程、DMG 拖拽安装和本地开发证书签名。自签名不等于 Apple Developer ID 公证；办公 Mac 首次运行仍需遵循系统安全提示。

完整审查、动作映射、架构图与剩余限制见 [架构审查与监测能力](architecture-review-v0.5.md)。面向 Apple Silicon / macOS 14+，M2 / macOS 27 验证；未在 M5 实机验证。发行包仍包含本地推理运行时，无需安装 Python，无联网推理。
