# Kukusit v0.8.0

- 恢复确认改为三盏 🟢 依次柔和亮起，根据每项异常的实际恢复进度显示。短暂回歪会重置绿灯进度，不会清掉异常累计；提示不抢焦点，并尊重 macOS 减少动态效果设置。
- 锁屏、熄屏或休眠造成的中断，解锁亮屏后自动继续之前的监测；手动暂停仍然保持暂停。中断时停止摄像头并清除画面，恢复后重新等待可靠识别。
- 画中画记住拖动后的显示器、位置和尺寸，收起再打开或重启应用均可恢复。屏幕分辨率变化或外接屏断开时会调整到可见范围。
- 监控窗口聚焦或点击画中画获得焦点后，按空格暂停／继续监测；长按不会重复切换，设置输入、更新窗口和其他应用不受影响。

- 提醒语精简为直接动作，例如“头向左扶正”“双肩放平”“手离开嘴唇”“放松下颌”，口部示范名称保留在诊断信息中。

105 项核心检查、实际摄像头的模拟系统中断／解锁恢复测试、画中画跨重启保存及键盘操作核验通过。恢复动画使用合成输入验证，不保存摄像头画面。沿用原生签名更新机制，保持动态库验证；可从 0.7.x 应用内检查更新。

Apple Silicon、macOS 14 及以上。仍为本地自签名发布，未经 Apple 公证。
