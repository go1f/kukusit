# Kukusit v0.6.0

歪头、高低肩及口部变化现在各自累计时间、各自确认恢复，交叉或叠加不会互相清零。左右方向变化只更新提示方向。持续异常的通知一直显示，一项恢复只移除该项；最后一项确认恢复后短暂显示“已恢复”。看不清、转头、离座、暂停或校准时保持安静，短暂波动仍保留各自计时。

增加默认开启的嘴角变化观察，支持张嘴时的嘴角位置、口宽及唇部不对称变化。个人动作示范支持下颌紧张、上唇、下唇、歪嘴和舌部动作的外观匹配：先录自然放松 3 秒，再逐项录动作 3 秒。要求至少 2 秒连续有效观察；匹配差距与区分裕度可自行调节。它不确认咬合力量、哪颗牙接触了嘴唇或舌头，也不用于诊断磨牙。说话、表情和关键点误差仍可能影响匹配，真实动作的误报/漏报率尚未量化。

镜像移至全局“视频预览”页面，同时影响主窗口和画中画，新安装默认关闭；已有保存选择保留。运行中的 Dock 图标跟随系统浅色/深色模式变为纯白/纯黑底，Finder 使用透明兼容图标。

验证：91 项核心检查通过，覆盖叠加、交叉、方向变化、分项恢复、短时回正、丢点、2 Hz 口部识别及个人示范的负样本/区分裕度。合成 AppKit 演示验证持续提示超过 4 秒仍显示、部分恢复后继续提醒、不抢焦点及最终恢复淡出；设置页面和默认镜像已视觉核验。采样存储检查覆盖连续性、私有文件权限、读取回环和失败回滚。

发行包包含本地推理运行时，无需 Python，无联网推理。个人参考与动作示范、照片和本机验证数据均不包含在发行包中。面向 Apple Silicon / macOS 14+，在 M2 / macOS 27 验证，未在 M5 实机验证。本地开发证书自签名，未进行 Apple Developer ID 公证。

使用方法与能力边界见 [监测与采样说明](https://github.com/go1f/kukusit/blob/v0.6.0/docs/monitor-v0.6.md)。
