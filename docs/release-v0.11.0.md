# KukuSeat v0.11.0

- 应用改名为 KukuSeat，应用图标采用原图小灰猫加纯白底，状态栏恢复早期白色实心 v4，保留下颌、眼睛与嘴巴切口。
- 提醒改为可拖动的小灰猫桌宠：保存屏幕与相对位置，断开外接屏时回到可用屏幕；可右键隐藏，并从状态栏找回。
- 漫画气泡在小猫周围近距离、不规则排布，多种异常独立出现；气泡约 1.8 秒缓缓吹起，同一轮保持位置，其它提醒恢复时不重新洗牌。
- 点击小灰猫或任一气泡，收起所有提示并全局静默 30 秒，小猫保留；恢复期间保留原调整语，确认恢复后加勾并短暂保留。
- 保留肚皮微呼吸与原图轮廓；暂停或系统中断时隐藏，恢复监测后返回，系统“减少动态效果”关闭呼吸与缩放。不抢键盘焦点，气泡之间的桌面可直接操作。

保留既有校准、偏好、原生签名更新与动态库验证。安装包包含本地推理运行时，无需另装 Python。Apple Silicon、macOS 14 及以上；M5 实机尚未核验。本版继续使用本地开发证书自签名，未进行 Apple 公证。

兼容旧版自动更新，GitHub 仓库与附件文件名继续使用 Kukusit；DMG 内应用为 KukuSeat.app。经旧版自动更新后，磁盘路径可能仍为 Kukusit.app，但显示名称为 KukuSeat。

验证：111 项核心检查，新增负坐标多屏、边缘气泡碰撞和保留位置检查，提醒生命周期、30 秒全局静默与原生离屏绘图检查。实际鼠标拖动与手感尚未进行人工核验。
