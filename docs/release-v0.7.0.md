# Kukusit v0.7.0

- 新增自动检查更新：默认每天在后台检查一次，可在“设置 → 应用更新”中关闭。不会自动安装或强制重启。
- 应用菜单、状态栏面板和设置页均可手动“检查更新”。发现新版后可立即更新、稍后提醒或跳过此版本。
- 新增应用内下载、安装和重新启动。镜像、敏感度、校准与个人口部示范数据继续保留。
- 更新源为公开 GitHub Release；使用原生 URLSession、CryptoKit 和独立安装助手。版本信息由 Ed25519 签名，下载包在解压前核验 SHA-256，安装前验证应用证书与签名。无须配置 GitHub Token。
- 不收集系统信息统计；摄像头画面、个人校准和示范不参与更新请求。

0.6.x 没有更新器，需手动下载安装此版本一次，此后的版本可在应用内更新。Apple Silicon、macOS 14 及以上。仍采用本地自签名证书，未进行 Apple 公证。

保留 Hardened Runtime 和动态库验证，不加载第三方更新框架。替换失败或重新打开失败会恢复原应用，成功后的原版本保留在同目录隐藏备份中。
