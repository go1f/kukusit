# Kukusit v0.4.4

修复头部偏离 4–6°仍显示“头部接近参考”的问题。

- 头部异常起点从 8°降为 4°。可靠且持续偏离默认 25 秒才提醒。
- 头部恢复范围从 5°收紧到 2°，连续回正 2 秒才确认恢复；不足 2 秒保留计时。
- 2°到 4°之间显示“轻微偏离参考”，已有异常状态时继续使用恢复阈值维持计时，避免在阈值附近反复切换。
- 判定使用与界面头部偏移一致的脸部相对个人参考角度，肩线同向倾斜不再抵消成正常；头肩同向倾斜用一般坐姿提示，避免误说成独立歪头。
- 肩部独立阈值保持 8°进入、5°恢复。转头、低质量识别时静默及短暂丢点保留计时规则继续生效。

包含正负 4°、5°、6°，有肩线及仅头部，3°恢复边界，头肩同向倾斜及肩部单独变化的自动回归检查。角度是摄像头相对个人参考的估计值，阈值是工程设置。

下载 `Kukusit-0.4.4-macOS-arm64.zip`，退出旧版后替换应用；已有校准继续可用。支持 Apple Silicon / macOS 14+，包含本地推理运行时，无需安装 Python。M2 / macOS 27 构建验证，未在 M5 实机测试。发行包仍为 ad-hoc 签名，未经 Developer ID 公证。
