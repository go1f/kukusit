# Kukusit v0.10.0

- 恢复进度改为左侧顺时针绿色圆环，保留原有坐姿调整语；确认恢复后显示完整闭环并停留约 3 秒，再淡出。
- 提醒框固定圆角，同一轮提示只平滑扩展，不随文字反复收缩。短暂识别波动在 2 秒内保留已有提示并冻结恢复进度，长时间看不清仍保持安静。点击后全局静默 30 秒，期间新异常和自检也不弹出；之后需要新的清晰异常观察才会再提醒。
- 状态栏改为原生左对齐菜单，状态文字预留固定空间；新增镜像开关，移除状态栏里的检查更新项。更新功能继续保留在应用菜单和设置页。
- 监控窗口新增“双画面对照”开关，默认关闭；打开后上方为非镜像原始画面，下方为镜像画面。选项会保存，预览共用摄像头输入与姿态分析。
- 主窗口的状态文字、说明和指标区保留固定尺寸，切换状态及双画面不会自动改变窗口大小。演示中的开始／暂停按钮继续使用合成输入。

沿用原生签名更新，保持动态库验证。Apple Silicon、macOS 14 及以上；M5 实机兼容性仍待验证。

验证通过：111 项核心检查、提醒生命周期与 30 秒静默边界、切换参考／暂停不误报恢复、12 次状态与双画面切换下的窗口和菜单尺寸检查、恢复前中后圆角透明区域检查，以及本机摄像头的双预览独立镜像连接检查。布局渲染使用合成画面，未保存摄像头图像；设置、校准和个人示范完整性检查通过。
