# v0.4.0 · 便携发行与交互修正

日期：2026-10-10。

## 交互调整

1. 状态栏菜单改为按图标的屏幕坐标定位，图标与面板间距约 4 点。高度取内容实际尺寸，避免固定弹出框的空余与偏移。
2. 菜单增加直接的“打开监控窗口”入口。主窗口是居中视频、底部姿态偏移和暂停；无需先进入 PiP。
3. 设置从监控面板移到独立窗口，按提醒、画中画、校准分组；高级模型和诊断默认折叠。
4. PiP 按视频比例和控制栏高度计算尺寸，移除底部占位。右上角放大和“更多”各有独立 28 点点击区域，下拉箭头隐藏，避免重叠。
5. “待确认恢复”保留异常累计值。回正不到 2 秒后重新异常，继续累计；回正时间和重新稳定所需时间不计为异常。连续回正达到 2 秒才结束当前异常。低质量、离座或过长的数据缺失仍会保持安静并重置候选计时。

## 发行结构

应用由 Swift / AppKit / SwiftUI 界面、本地冻结的 MediaPipe Pose 运行时和官方模型组成。推理运行时放在应用资源中的 `PoseRuntime`，运行配置使用相对应用路径，没有开发环境的 Python 绝对路径依赖。

目标架构为 arm64，可在 Apple Silicon M 系列上运行；macOS 27 是当前验证环境。M5 使用相同 arm64 架构，但本次没有 M5 实机验证。

模型和框架在本机推理。发行包不附带个人参考、实拍统计、机器标识或工作场景画面。新的办公 Mac 上应重新校准。

## 校验与签名

发行构建校验嵌套代码签名，运行冻结后端的空白帧／取消检查，并生成 ZIP 的 SHA-256 文件。发布前会将应用复制到独立目录，再运行同一检查，以确认脱离源码目录仍能工作。

此版本为 ad-hoc 签名，未进行 Developer ID 公证。下载后的首次打开可能需在 macOS“隐私与安全性”中按系统提示批准。应用不会更改或关闭系统安全保护。

源码可由构建脚本重建；个人状态与本机验证目录已在 Git 忽略规则中排除。
