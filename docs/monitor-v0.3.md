# 常驻监测与画中画 v0.3

日期：2026-10-10。应用仍位于 `dist/PostureDiagnostics.app`，显示名称为“坐姿监测”；应用标识保持不变，沿用已有摄像头授权与个人参考。

## 日常使用

- 启动后默认只有菜单栏图标，摄像头预览收起。已有个人参考和摄像头授权时，可按保存的设置恢复监测；手动暂停后下次启动保持暂停。
- 点击图标查看监测状态、开始／暂停、观看情境和 20 秒校准。点击“监测状态与设置…”打开完整窗口。
- 点击“画中画预览”打开小面板；也可以按住 Option 点击菜单栏图标直接切换 PiP。完整窗口的“画中画”按钮会切换为小面板。
- PiP 可以显示视频、骨架和头部／肩线偏移，也有暂停按钮。右上角放大按钮切回完整窗口，并展开预览。
- PiP 的“更多”菜单支持显示／隐藏视频、骨架、置顶和大小；完整设置还可以选择显示器及四角位置。面板支持拖动和手动缩放。
- 关闭或收起预览窗口只隐藏画面，监测继续；点击“暂停监测”才停止采集并释放本地模型助手。

应用激活时，`⌘⇧D` 打开完整窗口，`⌘⇧M` 显示菜单栏状态，`⌥⌘P` 切换 PiP。没有强制常驻的视频窗口，也不增加系统登录项。

## 提醒行为

默认连续偏离 **25 秒** 才提醒，同类及跨类提示共用 **3 分钟** 冷却。设置可以把持续时间调整为 20–60 秒，冷却调整为 2、3 或 5 分钟。

提醒条位于工作显示器顶部、菜单栏下方，约 0.25 秒淡入、4 秒后淡出；没有声音、确认按钮或可点击控件，也不成为键盘焦点窗口。恢复连续确认约 2 秒后，若提醒仍在显示，会短暂变成“已恢复”；提示已经消失时，不另外弹出恢复通知。

肩线偏移提示“坐直一点，放松肩膀”。头部相对肩线倾斜时，按实际人体左右提示向左侧或右侧扶正；预览镜像不会反转方向。单肩变化和整体侧倾不会直接被当作独立歪头，软件也不判断疾病或测量颈椎角度。

只有当前参考匹配、脸与双肩质量达标、头部角度可用且观看方向接近已校准情境时，才累计偏离时间。转头、离座、多个目标、抖动、丢帧、数据过期、校准期间和模型失败都保持安静，并打断待确认计时。缺失时间不累计为异常，未知状态也不被当作已经恢复。

如果上屏和下屏都校准过，按当前头部方向选择较接近的参考；不把鼠标位置当作注视真值，不自动漂移个人基线。

## 原生窗口实现

`NSStatusItem + NSPopover` 是日常入口。完整窗口是普通 `NSWindow`，PiP 与提醒是独立的 `NSPanel`。

提醒使用 `nonactivatingPanel`，禁止成为 key/main window，穿透鼠标点击；只调用排序和淡入淡出，不激活应用。PiP 也使用非激活面板，用户主动点击放大时才激活完整窗口。[Apple 非激活面板接口](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel)

显示器路由只读取前台应用窗口的拥有者 PID 与几何边界，选择与窗口交集最大的显示器；不会读取窗口标题、屏幕图像或其它应用内容。无法得到窗口边界时，使用最近工作显示器或鼠标所在屏幕。PiP 固定显示器断开时回退到当前工作显示器。[Apple 窗口几何信息接口](https://developer.apple.com/documentation/coregraphics/cgwindowlistcopywindowinfo(_:_:))

监测与显示解耦：预览全部隐藏时，不生成 `CGImage`，也不执行仅用于绘制的密集人脸关键点请求；姿态推理和提醒继续。打开 PiP 或展开预览后，按显示需要恢复图像／骨架数据。图像不保存、不上传。

## 验证

- 原有 25 项核心检查，加上 13 项提醒行为检查，共 38 项通过。覆盖方向、短暂偏移、三分钟冷却、缺失时间、转头、抖动、情境切换、单肩／整体侧倾、恢复、暂停和迟滞。
- Swift 与本地 MediaPipe 助手的帧管道和取消检查通过。
- 合成姿态驱动的原生交互检查覆盖提醒出现、恢复、冷却、转头保持安静，以及全部预览隐藏后的监测。检查了非激活面板属性、鼠标穿透和焦点保持。
- PiP 的视频／骨架／数值／暂停按钮及一键放大，已通过原生界面检查。
- 菜单栏弹出面板的状态、暂停、校准情境、PiP 入口已检查；正式版重新启动后，真实后台检查得到 60 个已分析帧、约 6.01 Hz、管线 p95 约 58.23ms，既有参考匹配、25 秒／180 秒规则启用。完整窗口与 PiP 均隐藏，图像和绘制用骨架请求关闭，最后帧也不含预览图像。

本次证据位于 `validation/core-checks-v0.3-2026-10-10.txt`、`validation/reminders-ui-v0.3-2026-10-10.json` 和 `validation/background-v0.3-2026-10-10.json`。后台检查时长较短，不代替长期耗电试验。

自动化界面检查使用加速的合成输入，不使用真实摄像头、不覆盖个人参考，真实监测继续采用设置中的 25 秒和 3 分钟。它验证软件交互，不代表坐姿分类准确率。复杂全屏应用、多 Space 与长时耗电仍需要扩展验证；窗口已配置全屏辅助及跨 Space 行为。

当前仍是这台 Mac 的本机开发版，MediaPipe 助手依赖项目环境路径。既有校准数据保存在 Application Support，提醒与 PiP 设置保存在应用自己的 UserDefaults。
