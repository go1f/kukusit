# Kukusit v0.4.3

修复监测经常停在“暂不可判定”、偶发丢点导致计时反复清零的问题。

- 脸部角度和观看方向可靠时独立判断头部。肩部丢点或只有头部参考不再阻断歪头提醒；肩线缺失用 `nil` 表示，不伪造水平肩线。肩部提醒仍要求可靠肩线和对应参考。
- 肩部与脸部关联支持可靠的鼻、眼或耳关键点，适配 MediaPipe 没有颈部点的情况。
- 稳定观察改为约 0.5 秒起步、1.2 秒滚动中位数及离散程度检查，至少需要 3 个有效样本。孤立跳点和缓慢倾斜可以继续观察，反复大幅抖动、转头过程保持安静。
- 同一参考下，识别丢失或姿态波动不足 2 秒保留累计时间；期间不累计也不提醒。超过 2 秒清除待提醒计时。明显转头、多个目标、长时间无帧及参考切换立即清除相关证据。
- 相对参考的观看方向容许范围调整为左右 28°、俯仰 35°，用于容纳稳定看上方屏幕；额外排除绝对侧转超过 40°或俯仰超过 55°。这些值是工程过滤阈值，并非医学界限，也不把抬头低头本身判为坐姿异常。
- 主窗口、菜单及 PiP 显示具体等待原因；肩部不可用时显示头部监测范围。导出数值摘要增加各判定状态的样本计数，便于排查。
- 自动选择上下屏参考增加 8°距离余量，避免临界方向附近来回切换；方向暂时不可用时保留当前参考，避免把一次识别波动误当成情境切换。
- 保留持续偏离 25 秒、连续回正 2 秒确认恢复、静音提示和 3 分钟冷却。肩线缺失不能确认肩部异常已经恢复。

发行包：`Kukusit-0.4.3-macOS-arm64.zip` 与 SHA-256 文件，包含推理运行时和模型，无需 Python。最低 macOS 14，面向 Apple Silicon；在 M2 / macOS 27 验证，未在 M5 实机测试。旧版个人参考继续可用。发行包仍为 ad-hoc 签名，未经 Developer ID 公证。

验证覆盖头部独立判定、肩部抖动与丢点、短暂及持续识别失败、慢速歪头、角度离群值、上方屏幕俯仰、转头、计时和恢复回归，以及应用构建、内置姿态引擎与解压运行。
